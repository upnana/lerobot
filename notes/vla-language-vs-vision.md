# 单任务 VLA：语言 vs 视觉

基于 SO101 + SmolVLA 在 **蓝块 → 黄盘**（单一指令，约 90 条 demo）上的微调结果，以及三组语言–视觉消融实验整理的学习笔记。

## 一句话结论

单任务微调之后，策略更像是针对训练场景（蓝块 + 黄盘）的 **视觉→动作 skill**。语言提示 **基本被忽略**：只改物体颜色会破坏抓取，只改文本指令却往往不影响成功。

**Zero-shot 角度（明确写出）：** 微调后的策略几乎没有 **zero-shot 语言遵循** 能力，对 **未见过颜色物体** 的 zero-shot / OOD 迁移也很弱；成功强绑定在「训练过的视觉 skill」上。

| 发现 | 概括 |
|------|------|
| 视觉主导 | 主要行为驱动力 |
| 语言很弱 | 指令接地弱 / 被忽略 |
| OOD 颜色失败 | 黑块抓取失败 |

## 实验矩阵

| 试验 | 语言任务 | 真实场景 | 行为表现 | 含义 |
|------|----------|----------|----------|------|
| 1 | 正确：*pick up the blue block…* | 黑块 + 黄盘 | 会去抓，但不准 / 抓不到 | 正确语言救不了 OOD 外观 |
| 2 | 错误：*pick up the black block…* | 蓝块 + 黄盘（训练分布内） | 成功：抓取与放置正确 | 视觉匹配训练时，错误语言会被忽略 |
| 3 | *pick up the black block…* | 黑块 + 黄盘 | 有抓取动作，仍抓不到 | 失败跟着视觉物体走，而不是「语言是否对上物体」 |

**对照设计：** 试验 2 vs 1/3 把语言与外观分开；试验 1 vs 3 说明就算语言也说 black，仍无法修好黑块失败。

## 更深层含义

### 视觉 / 外观（主导）

训练分布几乎都是蓝块像素和蓝块几何。测试时：

- **有蓝块** → skill 会执行（哪怕文本写 black）
- **有黑块** → 可能出现接近/抓取先验，但位姿与可抓特征 OOD → 抓偏或抓不稳

### 语言接地（很弱）

微调时指令几乎恒定，语言 token 几乎没有可区分的学习信号。VLM 通路还在，但策略可以把语言当成固定偏置。

因此验证结果是：模型学会了可用的 pick-place 动作策略，但 **没有** 开放词表 / zero-shot 按颜色跟随指令的能力。

## 学习笔记

### 1. 消融实验怎么设计

要分开「语言」和「视觉」，按 2×2 想：

- （正确 / 错误语言）×（分布内 / OOD 物体）

你的三组试验覆盖了关键格子：**语言错 + 视觉分布内 → 仍成功**；**视觉 OOD → 无论语言对错都失败**。

### 2. 为什么单任务 VLA 常常「不听字」

- 语言恒定 → 决策不需要靠词来区分
- 视觉 + 本体感觉已足够模仿演示
- 训练指标是轨迹/动作拟合，不是指令忠实度
- 窄域微调可能把预训练 VLM 的语义「冲掉」（过度特化）

### 3. 和 zero-shot 的关系

| 你的试验 | Zero-shot 解读 |
|----------|----------------|
| 指令改成 “black”，场景仍是蓝块 → 仍成功 | **不是**对错误新指令的 zero-shot 遵从；语言基本没用上 |
| 训练从未见过黑块 → 抓失败 | 对新颜色物体的 **zero-shot / OOD** 迁移很弱 |
| 文本正确说 “blue” + 实物黑块 → 仍失败 | 无法用语言做 **zero-shot 换目标** |

### 4. 怎样才真正测到颜色跟随

- 多任务 / 多颜色 demo，指令要相应变化
- 打乱物体位置，避免「颜色 = 固定位置」捷径
- Hold-out 评测：同一场景只改指令（blue / white / black）
- 后续叠放任务（先蓝进盘，再白叠蓝）能逼出顺序 + 颜色；仍建议位置随机

### 5. 失败模式分类（方便面试）

| 模式 | 现象 | 可能根因 |
|------|------|----------|
| 语言忽视 | 指令错、场景对 → 仍成功 | 单任务条件；语言未参与决策 |
| 外观 OOD | 新颜色/纹理 → 抓取失败 | 视觉表征 / skill 适配训练物体统计 |
| 部分 skill 先验 | 有接近/抓取动作但失败 | 粗阶段被记住；精细对齐依赖分布内视觉线索 |

## 求职面试

### 30 秒口述

> 我在 SO101 上用单一 pick-place 任务微调了 SmolVLA，并做了语言–视觉消融：只改文本指令时，只要还是训练过的蓝块场景仍能成功；换成黑块后，即使指令正确也会抓失败。说明策略学到的是视觉条件 skill，几乎没有 zero-shot 语言遵循，也对未见颜色迁移很弱。下一步应采集多颜色、多指令、位置打乱的数据。

### 常见问答

**Q：你怎么证明模型没有在用语言？**  
A：做反事实：保持训练过的视觉场景，只把指令改成未训练过的颜色词（“black”）。成功率仍然高。若语言对选目标是因果的，成功应明显下降，或行为应系统性变化。

**Q：为什么黑块上还有抓取动作，却抓不到？**  
A：行为克隆常学到阶段结构（接近 → 闭合夹爪 → 抬起 → 去托盘）。粗阶段可以部分迁移；高精度抓取依赖接触几何/颜色等视觉特征。黑块对这些特征是 OOD，闭环对齐就会失败。

**Q：怎么提升语言接地 / zero-shot 遵循？**  
A：

- 采集仅在语言相关因素上有差异的多任务对（颜色 / 顺序）
- 增加指令多样性，避免恒定 task 字符串
- 随机化位姿，防止「永远抓左边」捷径
- 评测协议：指令对调 + 颜色对调 hold-out
- 可选：减轻过度冻结 / 加强共训，让 VLM 语义更容易保留

**Q：这对 VLA 评测说明了什么？**  
A：离线 MAE、分布内成功率不够。还要做干预式消融（语言、物体外观、布局）。否则容易把「视觉 skill」误说成「VLM 理解了任务」。

**Q：这是不是预训练 VLM 的失败？**  
A：不一定。预训练可能已有颜色概念；窄域 demo 微调会让动作头忽略语言变化。先用多指令数据诊断，再归咎 backbone。

## 速记子弹

- 视觉主导
- 语言被忽视
- 几乎没有 zero-shot 语言遵循
- 未见颜色上的 zero-shot 迁移很弱
- OOD 颜色会打断抓取
- 需要多任务对比数据
- 消融比单纯成功率更重要
